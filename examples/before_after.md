# 改写前后对比集

> 真实段落对比，每对都通过 PaperPure 实测验证

## 案例 1：摘要开头

### 原 AI 风格
```
随着互联网的快速普及，垃圾邮件已成为网络信息安全领域的常见问题之一。
尤其是在中文场景下，邮件文本语义表达灵活、词语边界不明显，加之垃圾
邮件发送者常借助谐音替换、符号插入等手段规避过滤系统，使得传统基于
关键词匹配和人工规则的方法难以满足实际应用中对准确性和实时性的要求。
```

**问题诊断**：
- ❌ "随着互联网的快速普及"是 AI 万能开头
- ❌ "尤其是在中文场景下"AI 过渡套语
- ❌ "谐音替换、符号插入等"是三项排比
- ❌ 全段第三人称客观陈述，无"我"
- ❌ 无模糊限定词
- ❌ 句长全在 30-60 字之间

### v3 改写后
```
我做的这个项目主要是想解决中文垃圾邮件的识别这个问题。中文这种邮件
的处理一直比较麻烦，邮件里面的文本语义表达本身就比较灵活，词和词
之间的边界也不是很明显，再加上发垃圾邮件的人会用各种办法去规避
过滤系统，比如说会用谐音字去替换原来的字，或者在词语中间加进一些
奇怪的符号。这样一来，原来那种基于关键词匹配和人工规则的方法效果
就比较差了，在准确率和实时性上都不太能满足实际的需求。
```

**做对了什么**：
- ✓ 第一人称"我做的这个项目"开头
- ✓ "比较麻烦"+"不太能满足"同义冗余
- ✓ "比较""不是很明显""比较差""不太能"4 处模糊限定
- ✓ "比如说"过渡（学生口吻）
- ✓ 一逗到底长句，零破折号
- ✓ 三项规避手段改成"比如说...或者...一些奇怪的符号"非规整列举

## 案例 2：实验结果（数字密集段）

### 原 AI 风格
```
实验结果表明，模型在测试集上的准确率为 91.95%，F1 分数为 87.72%，
AUPRC 为 0.936，在与朴素贝叶斯和支持向量机的对比实验中均取得最优结果。
```

**问题诊断**：
- ❌ "实验结果表明"AI 套语
- ❌ "X 为 91.95%，X 为 87.72%，X 为 0.936"三项数据排比
- ❌ "均取得最优结果"标准 AI 收尾

### v3.1 进阶优化（数字段技巧）
```
模型在测试集上的准确率达到了 91.95%。F1 分数也算了一下，是 87.72%，
AUPRC 是 0.936。也就是说在 174 条测试样本里面，大概有 160 条左右是
判断正确的。和朴素贝叶斯比起来，我的模型准确率高出了 9.77 个百分点，
和 SVM 比起来也高出了 4.59 个百分点，整体的表现比这两个传统方法
都要好一些。
```

**做对了什么**：
- ✓ 数字间插入研究者反应（"也算了一下"）
- ✓ 用具体计算稀释概念（"大概有 160 条左右"）
- ✓ 把"均取得最优"展开成具体的"高出 9.77 个百分点"
- ✓ "我的模型"用第一人称
- ✓ "比较""都要好一些"模糊限定

## 案例 3：原理解释段

### 原 AI 风格
```
卷积神经网络（CNN）是一种以局部连接和权值共享为核心设计思想的深度
神经网络。CNN 的基本结构通常由嵌入层、卷积层、池化层、全连接层依次
组成，各层协同完成从原始输入到类别预测的端到端特征学习过程。
```

**问题诊断**：
- ❌ 教科书式标准陈述
- ❌ "嵌入层、卷积层、池化层、全连接层"四项排比
- ❌ 无任何研究者视角

### v3.1 进阶优化（原理段技巧）
```
卷积神经网络（CNN）的核心思路是局部连接和权值共享。这个模型最早是
为了图像识别设计的，后来才被引入到自然语言处理领域。CNN 一般由嵌入
层、卷积层、池化层、全连接层依次串起来，从原始输入到类别预测的特征
学习全部都在这条流水线里面完成。我研究了一段时间才搞明白每一层在
做什么。简单来说，嵌入层做的事比较直接，就是把离散的词语符号映射成
低维稠密的向量，让文本里面的语义信息能够以数值的形式参与后面的运算。
```

**做对了什么**：
- ✓ "我研究了一段时间才搞明白"研究者主体性
- ✓ "简单来说"学生口吻过渡
- ✓ "嵌入层做的事比较直接"主观判断
- ✓ "依次串起来""流水线"半口语化但仍学术

## 案例 4：综述段

### 原 AI 风格
```
综合来看，深度学习方法在语义理解、特征自动提取和模型泛化等方面较
传统方法具有明显优势。其中，TextCNN 在保持结构简洁的同时兼顾了训练
效率和分类性能，尤其适合中文垃圾邮件这类以短文本为主、强调实时响应
的应用场景。
```

**问题诊断**：
- ❌ "综合来看"AI 套语
- ❌ "语义理解、特征自动提取和模型泛化"三项排比
- ❌ "在保持 X 的同时兼顾了 Y 和 Z"对偶句式
- ❌ "尤其适合"AI 推荐句式

### v3 改写后
```
归到一处，深度学习方法在语义理解、特征自动提取还有泛化能力上对传统
方法的优势是肉眼可见的。其中 TextCNN 的位置我觉得比较有意思，它没有
最复杂的结构，但是简洁刚好让训练效率和分类性能保持在一个不错的平衡
点上，对中文垃圾邮件这种短文本、又强调实时响应的应用场景来说尤其
合适。基于这条考量，我把研究的核心模型定在了 TextCNN。
```

**做对了什么**：
- ✓ "归到一处"换掉"综合来看"
- ✓ "肉眼可见的"主观评价
- ✓ "我觉得比较有意思"插入研究者视角
- ✓ "我把研究的核心模型定在了"第一人称决策
- ✓ "比较""不错"模糊限定

## 总结：改写的本质

不是替换词，不是调语序，是**重新让文本里有"一个本科生在思考"的痕迹**。

最有效的 4 把武器（按效果排序）：

1. **零破折号** —— 直接砍掉 Claude 头号指纹
2. **第一人称"我"** —— 把"本研究"全部换成"我"
3. **模糊限定词** —— "比较/差不多/基本上"满天飞
4. **故意冗余** —— 一个意思用两种说法说一遍

这 4 招命中后，AI 率会从 50%+ 直接降到 25%+ 区间。剩下的 15% 靠"进阶优化"和"真实研究细节"。
